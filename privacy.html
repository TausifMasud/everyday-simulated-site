Privacy Policy

Effective 2 November 2026

This policy covers "Everyday Simulated Uploader" (the "Tool"), an internal application operated by Tausif Masud for the YouTube channel Everyday, Simulated.

Who uses the Tool

Only the channel owner. The Tool is not available to the public and has no other users.

What the Tool accesses

With the owner's explicit consent through Google OAuth, the Tool uses YouTube API Services to upload videos, thumbnails and captions to the owner's own channel and to set their metadata and publish time. It requests only the scopes needed for this (youtube.upload and youtube.force-ssl).

What data is stored

The OAuth access and refresh tokens are stored only on the owner's computer, in a local file that is never shared or uploaded anywhere. The Tool does not collect, store, sell or share any personal data of YouTube viewers or other users, and does not use cookies or analytics.

Google and YouTube

The Tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time at Google security settings (third-party access); deleting the local token file also stops all access.
